# Mini Mario — 2D Platformer

A Mario-inspired 2D platformer developed in Python as a college mini-project.

## Features
- Two grid-based levels built using NumPy
- Player movement, jumping, gravity, and platform collision detection
- Enemy movement and collision handling
- Coin collection and score tracking
- Persistent top-10 leaderboard using file handling
- Keyboard and on-screen controls

## Tech Stack
- Python
- Tkinter
- NumPy
- Object-oriented programming
- File handling

## Run Locally

1. Install Python 3.
2. Install NumPy:

   ```bash
   pip install numpy
   ```

3. Run the game:

   ```bash
   python mini_mario.py
   ```

## Controls
- Left / Right arrows or A / D: Move
- Space or Up arrow: Jump
